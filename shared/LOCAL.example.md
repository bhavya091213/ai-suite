Your own rules, for this machine only. Claude Code imports this file through
`~/.claude/CLAUDE.md` (`@~/.agents/LOCAL.md`); `sync-agents rules` copies it into
`~/.codex/AGENTS.md` between the LOCAL RULES markers. The installer creates it from
`shared/LOCAL.example.md` only when it is missing and never overwrites it, so anything
you write here survives `./install.sh`.
